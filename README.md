# Дом Быта - Интернет-магазин товаров для дома

Современный многостраничный сайт интернет-магазина «Дом Быта» с каталогом товаров, корзиной и адаптивным дизайном.

## 📁 Структура проекта

```
dom-byta/
├── index.html          # Главная страница
├── catalog.html        # Каталог товаров
├── about.html          # О компании
├── contacts.html       # Контакты
├── css/
│   └── style.css       # Основные стили
├── js/
│   ├── data.js         # Данные товаров
│   ├── main.js         # Основной JavaScript
│   └── catalog.js      # Скрипты каталога
└── images/             # Изображения (опционально)
```

## 🚀 Развертывание на GitHub Pages

### Способ 1: Через настройки репозитория

1. Создайте новый репозиторий на GitHub
2. Загрузите файлы проекта в репозиторий
3. Перейдите в **Settings** → **Pages**
4. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`
5. Нажмите **Save**
6. Через несколько минут сайт будет доступен по адресу: `https://ваш-username.github.io/имя-репозитория/`

### Способ 2: Через GitHub Actions

1. Создайте файл `.github/workflows/deploy.yml` со следующим содержимым:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Pages
        uses: actions/configure-pages@v4

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

2. Закоммитьте и отправьте изменения
3. Включите GitHub Pages в настройках репозитория

## ✨ Функционал сайта

- **Главная страница**: Приветственный блок, преимущества, категории товаров, популярные товары
- **Каталог товаров**: 
  - Фильтрация по категориям (Хоз. товары, Бытовая химия, Инструменты, Текстиль, Для кухни, Декор)
  - Фильтр по цене
  - Сортировка (по цене, по названию)
  - Переключение вида (сетка/список)
- **Корзина**:
  - Добавление/удаление товаров
  - Изменение количества
  - Подсчет общей суммы
  - Сохранение в localStorage
- **О компании**: Информация о магазине, статистика, преимущества
- **Контакты**: 
  - Контактная информация
  - Форма обратной связи
  - Социальные сети
  - FAQ
